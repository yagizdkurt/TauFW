# Merge Request Rules (Strict)

These rules are **mandatory for all merge requests**.

- **DO NOT change modules directly** for your analysis.
- **DO NOT access module internals** for your analysis.
- **DO NOT import utilities.** Use necessary modules.
- **Run all tests before pushing anything.**
- All personal analysis scripts **must go into `Analyses/Year/Name/...`**.
- **Before pushing legacy code**, read the [legacy code policy](LegacyCode.md) and **follow its requirements**.
