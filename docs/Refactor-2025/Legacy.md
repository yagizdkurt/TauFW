## How to read the reasons

The retirement decisions come from [Fitter's legacy README](../../Legacy/Fitter/README.md), [PicoProducer's legacy README](../../Legacy/PicoProducer/python/README.md), [Plotter's legacy README](../../Legacy/Plotter/README.md) and [the refactor change log](Refactor-2025.md). The descriptions below also use the files' comments, functions, commands and configurations. “Unreferenced” describes the cleanup's recorded findings about maintained workflows; it does not mean a file has never been useful or has no external users. A one-off study can be legacy without being broken.

PicoProducer files were archived on 2026-10-12; Fitter and Plotter files on 2026-10-13. They were kept for reference rather than deleted and consolidated under root `Legacy/` on 2026-10-14. Explicit module imports use `Legacy.<Component>.python.*` with the checkout root on `PYTHONPATH`. Preserving the internal package structure does not guarantee that dependencies or runtime behavior still work. The legacy READMEs describe location-dependent imports and paths that may require repair.

README files and `__init__.py` explain or organize the archive; they were not retired analysis implementations.

Known defects and corrections to older bug descriptions are consolidated in
[Legacy/Bugs.md](../../Legacy/Bugs.md), including the malformed merge command LEG-F02.
`Tests/PicoProducer/testSFs.py` explicitly imports the archived ROOT-based muon scale-factor class.
