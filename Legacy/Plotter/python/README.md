# Legacy/Plotter/python

Unmaintained modules and ROOT macros that were under `Plotter/python/`, archived on 2026-10-13. They keep their
path relative to `python/` and moved from `Plotter/python/legacy/` on 2026-10-14.
Explicit imports use `Legacy.Plotter.python.*` with the checkout root on `PYTHONPATH`
(e.g. `Legacy.Plotter.python.methods.JetToTau_MisID`).

The list of files, the reason for each, and usage notes are in [the Plotter archive README](../README.md).
